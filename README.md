# OP PICK LAB

오버워치 픽 연구소 — 영웅 정보, 상성, 조합과 팀 구성을 제공하는 비공식 팬 가이드입니다.

DB와 서버 없이 동작하는 한국어 오버워치 영웅·상성·맵 추천·조합 가이드입니다. Next.js 정적 내보내기 결과를 GitHub Pages에 배포합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

검증과 정적 빌드는 `npm run check`로 실행합니다. 빌드 결과는 `out/`에 생성됩니다.

## 데이터 검증

`npm run data:validate`는 영웅 ID, 상성 참조, 점수 범위, 검수일과 특수 문자 이름을 검사합니다. 데이터 변경은 내용을 검토한 뒤 정적 JSON에 반영합니다.

`npm run data:rates`는 아시아 PC 빠른 대전·경쟁전 통계를 갱신합니다. 두 조건 모두 영웅 목록·중복·값 범위 검사를 통과해야 기존 파일을 교체합니다. `npm run data:rates:test`로 잘못된 응답을 받았을 때 기존 파일을 보존하는지 검사합니다. 배포 빌드에서도 통계를 갱신하며, 수집 실패 시 배포를 중단해 기존 운영 결과를 유지합니다. 정기 실행 일정은 없습니다.

상성의 `verified`는 개별 검토 상태이며 게임 내 재현 검증을 뜻하지 않습니다. 기술 사례에는 효과·성립 조건·대응법·원문 주소를 기록합니다. 맵 추천은 조건부 전략 분석이며, 원출처와 수집 조건이 없는 기존 승률은 `legacyWinRate`로 보존하고 표시하지 않습니다.

전술 시너지는 `recommended`와 `held`로 구분합니다. 구체적인 사례 출처, 양쪽 영웅의 기술, 실행 순서, 조건·실패 요인과 패치 주의가 있는 항목만 추천합니다. `lib/data.ts`가 추천 항목만 팀 구성에 전달하므로 보류 항목은 자동 완성·다음 픽·시너지 점수에 포함되지 않습니다. 2026-09-10에는 일반 기술 2개, 일반 기술+궁극기 3개, 영웅 궁합 3개를 5v5 기준으로 제공하고 12개 후보를 보류했습니다. 6v6는 별도 사례 검토 전이며 게임 내 직접 재현을 수행한 것으로 표시하지 않습니다.

스킬 수치에는 공식 패치 출처, 적용 모드, 변경일과 확인일을 기록합니다. 공식 패치가 설명하는 일부 항목만 제공하며 5v5·6v6·스타디움 수치를 섞지 않습니다. 2026-09-09 갱신 범위와 남은 한계는 [검토 기록](docs/data-refresh-2026-09-09.md)을 참고하세요.

## GitHub Pages와 도메인

1. 공개 GitHub 저장소의 기본 브랜치를 `main`으로 설정합니다.
2. Settings → Pages → Source에서 **GitHub Actions**를 선택합니다.
3. DNS에 `opick` CNAME을 `<GitHub 사용자명>.github.io`로 추가합니다.
4. Pages 사용자 지정 도메인에 `opick.ggwp.kr`을 등록합니다.
5. 인증서가 발급되면 **Enforce HTTPS**를 켭니다.

`public/CNAME`과 `public/.nojekyll`은 정적 빌드 결과에 자동 포함됩니다.
