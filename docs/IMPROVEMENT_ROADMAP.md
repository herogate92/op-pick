# OP PICK LAB 개선 순서

사용자 승인: 2026-09-21, owherostats.com 비교 결과를 바탕으로 순서대로 단계별 진행.
각 단계는 구현 → 검증 → 커밋·원격 반영 → 배포 확인까지 완료한다.

1. 통계 요약 오류 수정 및 영웅 상세 통계 연결 — PR #25 배포 완료.
   - 모드·역할·검색 결과에 맞는 요약, 실제 통계 제공 인원 표시
   - 영웅 상세에 모드별 승률·픽률·밴률·집계 조건·수집 시각
   - 통계 목록에서 선택 모드의 상세 통계로 연결
2. 모바일 첫 화면 개선 — PR #26·#27 배포 완료. 6개 메뉴 우선 배치, 역할별 승률·집계 조건과 최근 반영 패치 표시. 모바일 배경 영상 로딩 제외.
3. 통계 필터·밴률 수집 확장 — 구현·실제 수집 완료, 배포 결과는 해당 PR 확인. PC·컨트롤러 × 아시아·아메리카·유럽 × 두 모드 12개 조건, PC 아시아 경쟁전 8개 등급을 수집. 밴률 원본 값 보존, 없는 값은 null 유지. 전장별 수집은 5단계에서 진행.
4. 수집 이력 저장 및 증감·패치 전후 추이 — 구현 완료, 배포 결과는 해당 PR 확인. 실제 첫 수집 자료는 PR #29로 보존. 최근 30회 이력을 공개 JSON에서 복원·누적하고 동일 조건·제공자의 이전 수집/이전 감지 패치 기록과 %p 증감을 비교한다. 패치별 경기 집계가 아니며 미기록 과거 수치는 만들지 않는다.
5. 맵별 통계·후보 비교·티어표 — 구현·실제 수집 완료, 배포 결과는 해당 PR 확인. 등록 전장 27개를 PC 아시아 경쟁전·전체 등급으로 수집(기존 포함 총 47조건). 최대 3명 후보 비교와 승률 구간 티어표 제공. S≥55%, A≥52%, B≥49%, C<49%; 픽률 1% 미만·체험·자료 없음은 미분류. 종합 추천 순위나 표본 신뢰도 추정이 아니다.

운영 원칙: 패치 기준 갱신 방침을 유지한다. 일별 추이는 별도 수집 주기 결정이 필요하며 자동으로 매일 갱신으로 바꾸지 않는다.
후속 통계 범위 확대(2026-09-22): 3지역·2입력 장치 전체에 경쟁전 전장별·등급별 통계 구현 및 실제 222조건 수집 완료(각 54영웅, 체험 영웅 미제공 값은 null). 맵 상세에도 지역·입력 장치 선택 제공. 전장별은 전체 등급, 등급별은 모든 전장 기준이며 전장·개별 등급 교차는 제외한다. 2026-09-24 GitHub 연결 복구 후 배포 재시도. 배포 과정에서 최신 222조건을 다시 수집하며 최종 성공 여부는 GitHub Actions 실행 결과를 확인한다.
전체 승률 차이를 직접적인 카운터 관계로 해석하지 않는다. 기술 상성·조합 근거 관리는 별도로 유지한다.
