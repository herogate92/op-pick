## 해석과 남은 제한

맵 설명은 전장 구조를 활용하는 편집 분석이다. 맵별 통계 순위를 새로 측정한 것이 아니며, 개편된 지형의 현장 재현도 하지 않았다. 부산·아이헨발데·파라이수는 새 동선 확인을 요구하는 주의를 표시하고, 아틀리스는 세부 지형 검증 전 조건부 설명으로 표시한다.

D.Va의 API 생명력 구성과 공식 9월 8일 5v5 기본 생명력 표기가 충돌하므로, 총 생명력을 추측해서 최신값으로 표시하지 않는다. 총량은 재확인 중으로 두고 공식 패치의 기본 생명력 200을 별도 안내한다. 마우가 방어력과 브리기테 생명력·방어력은 공식 패치 변경을 반영한다. 영웅 전체 메타데이터의 기존 확인일을 일괄적으로 최신 날짜로 바꾸지 않고 기술 설명 확인일을 분리했다.

통계 갱신은 두 조건의 영웅 수·중복·영웅 키·유한한 수치 범위와 유효값을 검사한 뒤 임시 파일을 원자적으로 교체한다. 배포 시 재수집하며 실패 시 기존 운영 사이트는 유지된다. 정기 갱신 일정은 추가하지 않았다.
